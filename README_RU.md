# RTYT VPN — Android starter project

Это стартовый Android-проект с логотипом и базовым интерфейсом RTYT VPN.

## Важно
Этот архив **не является готовым VPN-клиентом**. Кнопка CONNECT пока не создаёт VPN-туннель. Импорт позволяет выбрать файл, но разбор подписок и подключение VPN-движка ещё не реализованы. Не используйте этот APK как средство защиты трафика.

## Сборка APK через GitHub с телефона
1. Распакуйте архив.
2. Откройте свой репозиторий GitHub.
3. Создайте отдельную ветку или отдельный репозиторий для приложения, чтобы не затронуть сайт.
4. Загрузите содержимое папки `RTYT_VPN_Android` (включая скрытую папку `.github`) в корень Android-репозитория.
5. Откройте вкладку **Actions** и запустите **Build RTYT VPN APK** через **Run workflow**. Также сборка запускается при push в main/master.
6. После успешной сборки откройте запуск workflow → **Artifacts** → `RTYT-VPN-debug` и скачайте APK.
